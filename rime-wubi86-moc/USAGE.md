# 使用说明

moc 86 五笔日常使用速查。部署见 [README.md](README.md)，部署细节见 [dist/INSTALL.md](dist/INSTALL.md)。

## 方案选择

| 方案 | 内容 | 何时用 |
|---|---|---|
| `moc_wubi86_simp` | 纯极点 core（字+词） | 想要最干净的五笔，无英文混输 |
| `moc_wubi86_simp_plus` | core + 白霜 5.3 万词 + 英文混输 | 日常主力，中英都能打 |

鼠须管菜单或 `Shift+Ctrl+0` 切换方案。

## 基本打字

- 单字：打五笔编码，如 `a` → 工，`hkat` → 战
- 二字词：取两字前两码，如 `wgst` → 我们
- 三字词：前两字首码 + 第三字前两码
- 四字及以上词：各字首码
- simp_plus 打英文拼写直接出英文候选（如 `github` → GitHub），中文优先、英文靠后

## 候选操作

| 键 | 作用 |
|---|---|
| 数字键 | 选对应候选 |
| `;` | 选第 2 候选 |
| `'` | 选第 3 候选 |
| `[` / `]` | 上 / 下翻页 |
| 空格 | 选第 1 候选上屏；无候选时把原始字母上屏 |
| `Esc` | 清空当前输入 |

## 中英切换

- `Shift`（左 / 右）：提交当前候选 + 切中 / 英
- `Caps Lock`：保留系统大写锁定（不被输入法接管）

## 拼音反查

不会打的字，用拼音查五笔编码：先按**反引号键**再打拼音。

```
反引号 + zhan   →   候选「战」，注释显示五笔编码 hkat
```

## 工具（斜杠引导）

| 输入 | 结果示例 |
|---|---|
| `/rq` | 2026-07-01、2026年07月01日 |
| `/sj` | 14:30、14:30:25 |
| `/calc1+2` | 3 |
| `/calc(3+4)*2` | 14 |
| `R123` | 壹佰贰拾叁圆（金额大写） |
| `N20240115` | 农历日期 |
| `/fh` | ，。、；：？！《》（）【】 |

计算器支持四则运算与括号。

## 无候选不卡

打到一半发现是词表外的词（如 `openclaw`），打完全部编码后按空格，原始字母直接上屏；打错编码按 `Esc` 清空重来，不会卡住。

## 自定义

**手填个人词条**：编辑 `~/Library/Rime/moc_wubi86_user.dict.yaml`，格式 `文本<Tab>编码<Tab>权重`：

```
浮亏	iefn	50000
张三	ta	50000
```

权重填 50000 以上可排到候选第一位（一级简码 99999、二级简码 80000、普通词 ≈30000-40000）。保存后鼠须管「重新部署」生效。

**英文词量**：编辑 `work/build_moc_wubi86.py` 顶部 `ENGLISH_TOP_N`，重跑 build。

**保留生僻字**：编辑 `work/data/protect_chars.txt`，一行一个字（如 `镕`、`喆`），重跑 build。

## 部署后

`bash install.sh` 会清空 `~/Library/Rime`、拷贝新数据、**自动编译字典**（含反查 prism）。完成后切换到 moc 方案即可；若候选异常，鼠须管菜单点「重新部署」。
