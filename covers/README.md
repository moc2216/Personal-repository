# 就慢慢攒 · 公众号封面生成

固定底图加动态槽位，一条命令产出公众号头条版与方版封面。

## 使用

进入本目录运行：

```
python3 make_cover.py
```

本机若自建了 `cover` 命令（不随仓库分发），也可在任意目录直接运行。

- 文案写在 `slot.txt`，一行一句，回车即换行。
- 输出在 `out_slot/<文案摘要>/`，包含 1280×544 与 1080×1080 两张。
- `python3 make_cover.py --clean` 重建根目录的纯净定稿（会覆盖，平时不用跑）。

## 文件

| 文件 | 作用 |
| --- | --- |
| `make_cover.py` | 生成脚本（Pillow） |
| `slot.txt` | 本次槽位文案 |
| `封面资产_底图源文件.png` | 底图源文件，换季/换光线时替换 |
| `封面资产_字体_霞鹜文楷Medium.ttf` | 标题与槽位字体 |
| `封面定稿_..._头条版_1280x544.jpg` | 纯净定稿，只读 |
| `封面定稿_..._方版_1080x1080.jpg` | 纯净定稿，只读 |
| `封面定稿_..._无标题_头像版.jpg` | 头像用，手工从方版导出 |
| `示例_文件换行_头条版.jpg` | 多行槽位的示例 |
| `花盆树.png` | 备用插画素材，脚本未使用 |
| `封面制作说明书.md` | 完整设计与排障文档 |

## 头像

使用 `封面定稿_..._无标题_头像版.jpg`；它在方版基础上去了标题，适合圆形裁切。
