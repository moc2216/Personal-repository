# 五笔编码助手

输入中文，按五笔86组词规则生成编码并展示逐字取码；核对重复情况，确认后备份并加入个人词库，再请求鼠须管重新部署。编码与权重可手动修改。关闭最后一个窗口即退出程序。

**版本1.2（build 3）**，macOS 13及以上，Apple Silicon与Intel通用App。当前实机验证为Apple Silicon；Intel只完成编译与签名检查。

## 使用

1. 下载[Release中的助手ZIP](https://github.com/moc2216/Personal-repository/releases/download/moc-rime-wubi86-2026.10.08/wubi-code-assistant-macos-1.2.zip)，解压后运行 `Wubi Code Assistant.app`，也可放入Applications。
2. 配合本仓库的Rime数据使用时，先部署数据。已有 `~/Library/Rime/moc_wubi86_user.dict.yaml` 必须保留；首次使用可采用Rime数据中的空模板。当前助手固定写入这个文件，不管理其他个人词库。
3. 输入词语，自动生成编码与逐字取码。根据重复提示确认是否需要添加，可修改编码或默认50000权重。
4. 点击“添加并重新部署”，确认后才写入；个人表同词同码会阻止重复，同词异码可保留或替换。备份位于 `~/Library/Rime/.moc_wubi86_backups/`。

App使用本机构建的签名，未经过Apple公证。系统下载验证是否允许打开，以macOS的隐私与安全提示为准；不需要关闭系统安全保护。构建源码也可获得相同工具。

## 编码与查重

编码计算只使用随App提供的固定6500字单字表，按两字2+2、三字1+1+2、四字及以上取前三字与末字首码；单字使用完整码。不会采用基础词组或个人已有整词码覆盖计算结果。已知合法编码变体可能与某个词库的惯用码不同，可手动调整。

查重独立进行：个人词库同词同码阻止添加；当前方案已有同词同码时提示通常无需添加，但允许明确确认后增加个人权重。同词异码与同码异词分开提示，正常重码不阻止添加。手动修改后按最终编码重新核对。

方案识别依据Rime保存的最近方案选择，不是对每个应用输入上下文的实时会话探测。界面显示本次比对的方案名；在鼠须管切换方案后重新输入即可刷新。仅支持本仓库两个主方案，通过已部署schema的主translator字典和import_tables展开实际加载的词表，不扫描备用词库或反查字典。纯净不会把扩展词报为已有。

缺少方案记录、源码字典、未完成重新部署，或遇到不支持的列/引用格式时，明确显示“比对未完成”，不宣称词不存在；自动编码与手动填写仍可用。个人表自身无法校验时会阻止写入。内置单字表之外的字可手动填写；图像只作展示，不参与推算编码。

## 源码与构建

```sh
cd Source
swift test --disable-sandbox
scripts/build-app.sh output
```

需macOS开发工具及Swift 6以上。构建脚本生成通用App，复制固定单字表、拆字图、图标及许可，并执行本机签名。维护工具只用于开发，不是普通用户运行依赖。

源代码、单字表和必要资源均在Source；验证证据在tests；[来源与许可](NOTICE.md) 和 [交接](handoff.md) 同目录。Rime数据入口见仓库中的 `rime-wubi86-moc/README.md`。默认App下载包只含App、使用说明和许可，不含整套输入法数据或个人词条。
