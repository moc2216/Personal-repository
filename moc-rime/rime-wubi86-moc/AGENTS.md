# 项目边界

- 发布的是直接复制并由 Rime 部署的数据，不是安装程序。
- data 是唯一现役数据源，共15文件：两个主方案、一个反查依赖方案、六个字典文件、五个Lua文件及default.custom.yaml方案注册模板。
- 必须保留纯净/全功能切换：纯净加载个人表+基础；全功能加载个人表+基础+扩展，基础与扩展数据各存一份。纯净复用全功能通用配置，不复制完整配置。
- 保留五笔及反查补全、现有按键和辅助功能；冷门内容按明确用途理由和分来源相对排名审核；用户已授权自主清理，不再无条件保护所有编码原首选，不凭低频或缺失批量删除。
- 不添加安装器、平台探测、Python运行依赖或vendored库。注册模板仅配置两个方案、纯净排在首位；已有default.custom.yaml必须保留并合并，不能覆盖用户设置。
- optional 只放可选平台外观，默认ZIP不包含它。
- 不公开私人个人词条、备份、build、user.yaml 或学习数据库。
- 空个人表只作首次使用模板，说明必须要求保留已有同名个人表。
- Python标准库只用于维护测试和打包，普通使用者不运行它。
- 验证：python3 -m unittest discover -s tests -p 'test_*.py'。
- 打包：python3 tools/pack.py，输出 releases，不在真实用户目录验证。
- 词库原记录规范化校验在 tests/expected.json；策略有意修改后重新审核更新，不能为过测试盲改哈希。
- 当前行为证据在 tests/native-result.json；Windows/Linux前端尚未实测。

- 词频只比较同一交集参考词条、分词长的来源内排名；缺失unknown。禁止直接混加原始数值、相同次数阈值、将Rime权重当真实频率。英文Google排名独立保护。
- 本轮删除明细在reports/removed.tsv，可按原位置恢复修改前规范化记录；cleanup_summary固定前后摘要，不能抹去旧摘要掩盖误删。保留词权重本轮未重新校准。
