## 二、设计定稿说明

- **画面**：深夜真实书桌——米家台灯 1S（细立柱/横条灯头/转轴橙红线环/薄圆底座，退到桌沿）照着摊开的涂金格子上色本；旁边是亮着表格的笔记本、扣着的手机、玻璃杯、桌角笑脸积木
- **概念**：本子作为品牌锚点出现，进度由**标题下方的动态槽位文字**承载（早期方案尝试在底图本子上「画」格子，但本质是贴图不是真在纸面，已弃用）
- **标题**：就慢慢攒（固定不变）
- **风格关键词**：真实生活气息、深夜、冷暖对比、极简、有生活痕迹

## 四、一键生产

本机另可自建 `cover` 命令（不在仓库内）。

```bash
# ① 日常最简：先编辑 slot.txt，再直接运行（输出到 out_slot/<摘要>/，不动定稿）
python3 make_cover.py

# ② 重建纯净定稿（会覆盖根目录两张 JPG，平时不用跑）
python3 make_cover.py --clean

# ③ 临时改文案：命令行直接写（不想编辑文件时）
python3 make_cover.py --slot 第40天

# ④ 指定别的文案文件（默认已读 slot.txt）
python3 make_cover.py --slot-file other.txt
```

> · `--slot` 与 `--slot-file` **只能二选一**
> · **带槽位时输出到 `out_slot/<槽位摘要>/`** 子目录，**绝不覆盖**根目录两张纯净定稿
> · 子目录名规则：槽位前 24 字符（特殊字符转下划线），超长追加 6 位 md5；同名则复用同一子目录

#### 槽位文字容量

| 版本 | 字号 | 安全宽 | 单行约容中文 | 单行约容数字 |
|---|---|---|---|---|
| 横版 | 38 px | 500 px | ≈13 字 | ≈21 位 |
| 方版 | 34 px | 900 px | ≈26 字 | ≈45 位 |

竖排 3 行舒适；横版槽位约容 **30 个中文**，方版约 **70 个**。日常控制在 1~2 行最稳。

#### 三种手动换行写法（任选其一）

**① 从文件读（最省事）** —— 任意编辑器打开 `slot.txt`，回车就是换行：
```
Day 40
第 5 个里程碑
攒到第一个 1 万·然后 5 万
```

**② 命令行敲字面 `\n`** —— 注意是**反斜杠 + n**两个字符，不是 shift+enter：
```bash
python3 make_cover.py --slot "Day 40\n第 5 个里程碑"
```

**③ shell 的 ANSI-C 引号传真换行**：
```bash
python3 make_cover.py --slot $'Day 40\n第 5 个里程碑'
```

> 终端里按 shift+enter **不会**插入换行符，别这么试。

#### 断行规则（按优先级）
1. **`\n` 手动换行** —— 你指定在哪断就在哪断
2. **自动换行** —— 遇 空格 / `·` / `，` / `,` / `。` / `；` / `;` / `/` / `｜` 才断；标点留行末（中文标点不出行首）；单块超宽按字兜底
3. 手动断出的每段仍受安全区约束（横版 500 px / 方版 900 px），超长自动再折

**实用技巧**——想让某个词组整体不被拆开，用空格把它与前后隔开即可：
```bash
python3 make_cover.py --slot "攒到第一个 1 万·然后 5 万·然后 10 万"
# → 攒到第一个 1 万·然后 5 万· ／ 然后 10 万  （「5 万」整体保留）
```

## 六、使用规则

1. 两张纯净定稿锁死不改，每次发文直接复用
2. 动态槽位只在需要时加字；用 `--slot-file` 最自然，编辑器里直接写多行
3. 底图源文件**不要丢失**——它是一切迭代（换季节、换光线、加元素）的起点
4. 想让进度感更强：不建议在底图上后置叠加格子（早期方案已证明会「贴纸感」）。正解是换一批底图，让进度痕迹真实长在纸面上（真实拍摄或 AI 重绘时就把格子画进去）

## 七、常见问题

**Q: `ModuleNotFoundError: No module named 'PIL'`**
装依赖：`pip install pillow`

**Q: 报错 `❌ 找不到资源：xxx`**
资源必须和 `make_cover.py` 在同一目录；常见漏拷：字体 / 底图。

**Q: 想从别的目录直接调用脚本，能跑吗？**
能。脚本用绝对路径解析资源，从哪都能跑：
```bash
python3 /path/to/就慢慢攒-封面资产/make_cover.py
```

**Q: 想保留纯净定稿的情况下测试不同槽位文案？**
带 `--slot` / `--slot-file` 跑会自动创建子目录，绝不覆盖纯净定稿。可放心反复试。

**Q: 同一种槽位文案跑两次会覆盖之前的输出吗？**
会覆盖同名子目录里的两张图。如果想保留历史，把子目录整体备份。

**Q: 字体 24 MB 太大了，能瘦身吗？**
可以用 fontTools 动态子集化到脚本实际用到的字符（≈2 MB），但有罕见字变方框的风险；当前不做此优化，备份好原字体即可。

**Q: 方版 1:1 是横版硬裁吗？**
不是。方版从底图右侧主体区独立取景 + 重排版，和横版是两套构图，所以两个尺寸都能贴边放主标题。
